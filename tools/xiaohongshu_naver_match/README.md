# 샤오홍슈 제품 영상 ↔ 네이버쇼핑 상품 매칭 정리표

- `xiaohongshu_naver_match_100.xlsx`: 검색어 100개, 샤오홍슈·네이버쇼핑 검색 링크, 영상 URL·상품 URL 입력 칸, 일치 여부·사용 허가 드롭다운, 진행 요약 시트가 들어 있는 엑셀 파일입니다.
- `build_match_sheet.py`: 위 엑셀 파일을 다시 만드는 스크립트입니다. (`pip install openpyxl` 후 `python build_match_sheet.py`)

## 왜 영상 주소가 비어 있나

샤오홍슈와 네이버쇼핑은 자동 프로그램 접속을 막고 있어 영상 주소를 자동으로 모을 수 없습니다. 확인되지 않은 주소를 지어내지 않기 위해 검색 링크와 입력 칸만 준비했고, 영상 주소는 사용자가 직접 확인해서 붙여넣습니다. 자세한 순서는 엑셀의 `사용법` 시트에 있습니다.

## 주의

남의 영상을 허락 없이 재업로드하면 저작권 문제로 삭제·제재될 수 있습니다. `사용 허가 확인` 열이 `원작자 허락받음` 또는 `직접 촬영`인 행만 실제 콘텐츠에 사용합니다.
