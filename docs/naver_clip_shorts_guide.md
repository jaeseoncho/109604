## 0. 먼저 알아둘 것 — "쇼핑 쇼츠"는 두 갈래입니다

네이버에서 짧은 영상으로 돈이 되는 길은 크게 두 가지입니다. 둘을 같이 굴려야 "푼돈"이 "꾸준한 돈"이 됩니다.

| 구분 | 길 A. 판매자 숏폼 (내 상품 팔기) | 길 B. 클립 크리에이터 수익 |
|---|---|---|
| 어디에 올리나 | 쇼핑라이브 **숏클립** + 네이버 앱 **클립**(내 상품 태그) | 네이버 앱 **클립** |
| 돈이 되는 방식 | 영상 → 상품 클릭 → 상담·결제 → 판매 마진 | 광고 인센티브, 쇼핑커넥트 수수료, 미션·어워즈 보상 |
| 조건 | 스마트스토어 판매자(숏클립은 등급 조건 있음) | 클립 크리에이터 선발·수익화 자격 충족 |
| 돈 크기 | 에어컨 1대 마진이 크므로 가장 중요 | 초반엔 작지만 꾸준히 쌓임 |

**현실 체크**
- 에어컨은 영상 보고 바로 결제하는 상품이 아닙니다. 클립의 역할은 "이 가게는 믿을 만하다 → 사진 상담 신청"까지 데려오는 것입니다.
- 그래서 클립에서 "설치비·추가비 조건을 정직하게 말하는 사장님" 캐릭터가 가장 강한 무기입니다.
- 크리에이터 수익(길 B)은 조회수와 자격 조건에 달려 있어 처음 1~2개월은 거의 0원일 수 있습니다. 실망하지 말고 길 A(상담 유입)를 기준으로 성과를 보세요.

## 1단계. 계정과 자격 준비 (1주차)

### 1-1. 네이버 앱과 클립 채널 만들기
1. 스마트폰에서 **네이버 앱**을 최신 버전으로 업데이트합니다. (클립 업로드는 PC가 아니라 모바일 앱에서만 됩니다.)
2. 네이버 앱 하단 메뉴 → **클립** 탭 → 오른쪽 위 **내 프로필**(또는 채널 만들기)로 들어갑니다.
3. 채널 이름은 스마트스토어 이름과 똑같이 맞춥니다. 예: `위너에어컨` 또는 `위너에어컨 구리남양주`.
4. 프로필 사진은 스마트스토어 대표 로고와 같은 것을 씁니다. 소개글에는 아래 문구를 복사해 넣습니다.

```
구리·남양주 에어컨·냉난방기 판매·설치 | 설치비·추가비 정직하게 설명 | 설치 전 사진 상담 010-9082-2174
```

### 1-2. 스마트스토어 쪽 준비
1. PC에서 **스마트스토어센터** 로그인 → **판매자정보** 에서 스토어 등급을 확인합니다.
2. 쇼핑라이브 숏클립은 라이브 송출 권한이 있는 **새싹 등급 이상** 판매자가 쓸 수 있다고 안내되어 있습니다. `[확인 필요: 2022년 안내 기준. 현재 등급 조건은 쇼핑라이브 스튜디오 공지에서 재확인]`
3. 등급이 부족하면 길 B(클립)부터 시작하고, 길 A 숏클립은 등급이 되는 시점에 추가합니다.

### 1-3. 클립 크리에이터 지원하기 (길 B의 출발점)
- 2026년 클립 크리에이터는 **2026년 2월 7일부터 상시 모집**이며, 최대 2만 명 규모로 선발한다고 보도되었습니다.
- 선발되면 **크리에이터 전용 프로그램·보상·광고 인센티브** 등의 혜택이 있습니다. 선발 시 최대 90만 원 보상이 있다는 보도도 있습니다. `[확인 필요: 보상 조건·금액은 지원 시점의 공식 공지 기준]`
- 2026년부터는 숏폼 영상뿐 아니라 **글+사진 게시물**도 수익 대상에 들어갑니다.

지원 순서
1. 네이버 앱 → 클립 → 내 프로필 → **클립 크리에이터 센터**(또는 검색창에 "클립 크리에이터 센터")로 들어갑니다.
2. **'26년 클립 크리에이터 지원하기** 버튼을 누릅니다.
3. 채널 소개에는 "에어컨 설치 현장, 설치비 안내, 구리·남양주 지역 정보"처럼 **주제를 한 줄로** 적습니다.
4. 지원 전에 클립을 최소 5~10개 먼저 올려 두면 심사에 유리합니다. `[추정: 공식 기준 아님]`

### 1-4. 쇼핑커넥트(네이버 제휴 마케팅) 이해하기
쇼핑커넥트는 "다른 사람이 내 상품을 홍보하고, 팔리면 수수료를 나눠 갖는" 구조입니다. 위너에어컨은 **두 입장 모두** 될 수 있습니다.

| 입장 | 무엇을 하나 | 돈 흐름 |
|---|---|---|
| 판매자로서 | 스마트스토어센터에서 내 상품에 커넥트 수수료를 설정 | 다른 크리에이터가 내 에어컨을 홍보 → 팔리면 수수료 지급 |
| 크리에이터로서 | 브랜드커넥트에 가입 후 다른 판매자 상품을 클립에서 소개 | 팔리면 내가 수수료를 받음 |

- 검색된 자료 기준: 판매자가 수수료를 자율 설정하며 **최대 50%**까지 가능하고, 간접 실적에는 기본 **1.8%**가 적용된다고 합니다. `[확인 필요: 스마트스토어센터 → 쇼핑커넥트 메뉴에서 현재 기준 재확인]`
- 크리에이터로서 참여하려면 **브랜드커넥트 가입 크리에이터**여야 합니다.
- 에어컨 판매자 입장에서는 수수료를 **너무 높게 걸지 말고**, 설치비 구조를 이해하는 사람만 홍보하도록 상품 설명에 "설치비 별도·현장 조건에 따라 추가비" 문구를 반드시 넣습니다.

### 1-5. 정산 정보
- 클립 크리에이터 센터의 수익 메뉴에서 **정산 계좌·세금 정보**를 미리 등록합니다. `[확인 필요: 메뉴 이름]`
- 사업자 명의로 받을지 개인 명의로 받을지는 세무사와 한 번 확인합니다.

**1단계 완료 체크**
- [ ] 클립 채널 이름·프로필이 스마트스토어와 같다
- [ ] 스토어 등급을 확인했다
- [ ] 클립 크리에이터 지원을 눌렀다(또는 지원 예정일을 적어 두었다)
- [ ] 쇼핑커넥트 메뉴 위치를 찾아 두었다

## 2단계. 클립에 붙일 상품 먼저 정리하기 (1주차)

영상이 아무리 좋아도 눌러 들어간 상품 페이지가 엉성하면 바로 나갑니다. 영상 올리기 전에 이것부터 합니다.

1. 클립에 태그할 **대표 상품 3~5개**를 고릅니다. (예: 벽걸이 냉난방기 1개, 스탠드 1개, 2in1 1개)
2. 각 상품에서 아래가 서로 맞는지 확인합니다.
   - 상품명 ↔ 모델명 ↔ 대표 이미지 ↔ 첫 번째 옵션 가격
   - 실외기 포함 여부
   - 기본 설치비 포함·별도 여부
   - 추가비 발생 조건(배관 길이, 앵글, 타공, 전기, 철거, 사다리차, 지역)
3. 상세페이지 **맨 위 3줄**에 "설치비 포함 여부"와 "사진 상담 안내"가 보이게 합니다.
4. 상품 태그는 스마트스토어센터 상품 수정 화면에서 넣고, 반드시 **[검색에 적용되는 태그 확인]** 버튼을 눌러 실제 적용된 태그를 확인합니다.

**2단계 완료 체크**
- [ ] 태그할 상품 목록(상품명·모델명·링크)을 메모장에 적어 두었다
- [ ] 설치비 포함/별도가 상품마다 명확하다

## 3단계. 촬영 장비와 영상 규격 (1주차)

필요한 것은 스마트폰 하나면 충분합니다.

| 항목 | 기준 |
|---|---|
| 화면 비율 | 세로 9:16 |
| 해상도 | 1080 × 1920 |
| 프레임 | 30fps |
| 파일 | MP4 (H.264), 오디오 AAC |
| 길이 | 클립: 15~60초 권장 (첫 3초가 가장 중요) `[확인 필요: 클립 최대 길이]` / 쇼핑라이브 숏클립: 2분 이내 `[2022년 안내 기준]` |

촬영 팁
- 스마트폰을 **세로**로 잡고, 설정에서 1080p 30fps로 맞춥니다.
- 밝은 곳에서 찍고, 목소리는 스마트폰을 입 가까이 두거나 저렴한 핀마이크를 씁니다.
- 자막은 꼭 넣습니다. 소리 없이 보는 사람이 많습니다. (네이버 앱 클립 편집기 또는 CapCut·VLLO 같은 무료 앱)
- 배경 음악은 **네이버 앱 안에서 제공하는 음원**만 씁니다. 외부 유행 음원을 넣으면 저작권 문제로 삭제될 수 있습니다.
- 고객 집 내부, 주소, 차량 번호, 얼굴이 찍히지 않게 합니다. 찍혔다면 모자이크하거나 그 장면을 뺍니다.

## 5단계. 업로드 — 실제로 올리는 순서 (2주차)

### 5-1. 네이버 앱 클립에 올리기 (길 A + 길 B 공통)
1. 네이버 앱 → **클립** 탭 → 화면의 **+ (만들기)** 버튼을 누릅니다.
2. 갤러리에서 찍어 둔 세로 영상을 고르거나 바로 촬영합니다.
3. 편집 화면에서 **자막·음원(앱 제공)**을 넣습니다.
4. **상품 태그(쇼핑 태그)** 항목에서 내 스마트스토어 상품을 검색해 붙입니다. `[확인 필요: 태그 메뉴 이름과 위치는 앱 버전에 따라 다름]`
5. 제목은 "궁금증 한 줄"로 씁니다. 예: `에어컨 설치비, 집마다 다른 이유`
6. 해시태그는 5~8개. 예: `#에어컨설치 #에어컨설치비 #냉난방기 #구리에어컨 #남양주에어컨 #에어컨추가비 #실외기 #설치전사진`
7. **게시**를 누른 뒤, 내 프로필에서 영상이 재생되는지, 상품 태그가 눌리는지 직접 확인합니다.

### 5-2. 쇼핑라이브 숏클립으로 상품 페이지에 붙이기 (길 A, 등급 조건 충족 시)
1. 스마트폰에서 **네이버 쇼핑라이브 스튜디오** 앱을 설치하고 판매자 계정으로 로그인합니다.
2. **숏클립 만들기**에서 영상을 올리고, 소개할 상품 목록의 **첫 번째 상품(또는 대표상품)**을 클립에 붙일 상품으로 지정합니다.
3. 숏클립 상태를 **서비스중 · 공개 · 전체노출(또는 부분노출)**로 둡니다. 이 조건이 아니면 상품 페이지에 안 보입니다.
4. PC 스마트스토어센터 → 상품관리 → 해당 상품 **[수정]** → 숏클립 등록 영역에서 방금 만든 숏클립을 선택하고 저장합니다.
5. 스마트폰으로 상품 페이지를 열어 상세 화면에 숏클립이 보이는지 확인합니다.

**5단계 완료 체크**
- [ ] 클립 1개가 정상 재생된다
- [ ] 클립에서 상품 태그를 누르면 내 상품이 열린다
- [ ] (등급 충족 시) 상품 상세에 숏클립이 보인다

## 7단계. 숫자 보는 법 — 어디를 봐야 하나 (매주 10분)

1. **클립 크리에이터 센터 → 통계**: 조회수, 시청 완료율, 팔로워 증감, 유입처·시청시간(2026년 추가 예정 항목). `[확인 필요: 메뉴 이름]`
2. **스마트스토어센터 → 통계 → 유입분석**: 유입 채널에 클립·쇼핑라이브가 잡히는지, 그 유입이 결제·문의로 이어지는지.
3. **판단 기준(단순화)**
   - 첫 3초 이탈이 많다 → 훅 문장을 바꾼다
   - 끝까지 보는데 클릭이 없다 → CTA 한 줄과 상품 태그를 손본다
   - 클릭은 있는데 문의가 없다 → 상품 페이지 맨 위 3줄(설치비·사진 상담)을 고친다
4. 매주 한 줄 기록: `날짜 / 올린 개수 / 총 조회수 / 문의 건수 / 결제 건수`

## 8단계. 수익 채널을 붙이는 순서

돈이 되는 순서대로 붙입니다. 아래로 갈수록 조건이 까다롭고 금액은 작습니다.

1. **판매 마진 (길 A)** — 클립 → 상품 → 사진 상담 → 설치. 가장 큰 돈. 첫날부터 가능.
2. **쇼핑커넥트 판매자 설정** — 내 상품에 수수료를 걸어 다른 크리에이터가 대신 홍보하게 함. 팔린 만큼만 지급되므로 위험이 적음. `[수수료율 현재 기준 확인 필요]`
3. **클립 크리에이터 광고 인센티브** — 선발 후 수익화 자격을 채우면 조회 성과에 따라 지급. 팔로워·조회수 등 세부 기준은 공식 센터에서 확인. `[확인 필요]`
4. **미션·어워즈 보상** — 이달의 해시태그 미션, 크리에이터 월간 어워즈, 활동 미션. 참여 자체가 노출에도 도움.
5. **쇼핑커넥트 크리에이터 활동** — 에어컨 소모품·리모컨·필터·청소 도구 등 **내가 실제로 쓰는 다른 판매자 상품**을 소개하고 수수료를 받음. 확인 안 된 제품 추천은 하지 않음.

## 10. 주의사항

- **정책 변경**: 클립 수익 조건, 쇼핑커넥트 수수료, 숏클립 등급 조건은 자주 바뀝니다. 매달 1회 클립 크리에이터 센터와 스마트스토어센터 공지를 확인합니다.
- **저작권**: 음원은 앱 내 제공 음원만, 남의 영상·사진 사용 금지.
- **개인정보**: 고객 집 내부, 주소, 얼굴, 차량 번호, 주문번호가 찍히지 않게 합니다.
- **과장 광고**: 4-3 표현 표를 지킵니다. 효율등급·성능 수치는 확인된 자료만 씁니다.
- **서비스 범위**: 확인되지 않은 수리·분해 세척·이전 설치를 제공하는 것처럼 말하지 않습니다.
- **AI 이미지·영상**: 실제 시공 사례처럼 보이게 쓰지 않습니다. 사용했다면 표시합니다.
