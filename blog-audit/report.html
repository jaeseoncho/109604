구리·남양주 위너에어컨 네이버 블로그 정밀 진단

대상: blog.naver.com/as1096 · 작성일 2026-09-18 · 근거 표시: 확인됨 자료로 직접 확인 추정 자료를 바탕으로 한 판단 확인 필요 사장님이 블로그에서 직접 확인

0. 먼저 알려드릴 것

이번 작업 환경은 네이버 전체 도메인 접속이 차단되어 있어(blog.naver.com, m.blog.naver.com, rss.blog.naver.com, 웹 아카이브·검색 캐시까지 모두 403 차단) 블로그 화면, 글 목록, 통계를 직접 열지 못했습니다.

그래서 아래 판단은 다음 자료를 근거로 했습니다.

  • 드라이브의 블로그 작성 규칙 문서 2종(8월 25일 v1·v2.1)과 실제 원고 3종(2025년 5월 HTML 원고, 8월 25일 5,000자 원고, 인스타 원고)
  • 블로그 글 생성에 쓰는 HTML 디자인 템플릿, 주제 은행 50·200선, 검색량 확인용 키워드 200개 파일(9월 10일)
  • 스레드 30편 계획(8월 25일~9월 23일), 사업자등록증 사진, 견적서, 구글 비즈니스 프로필 알림 메일
  • 웹 검색: “위너에어컨”이 LG 휘센 오브제컬렉션 위너 라인 제품명과 겹치는 점 확인

실제 블로그 화면에서만 알 수 있는 항목은 확인 필요로 표시했고, 마지막 장에 캡처해서 보내 주시면 2차 정밀 분석이 가능한 화면 목록을 정리했습니다.

1. 한눈에 보는 결론

방문자가 없는 이유는 한 가지가 아니라 “글이 검색에 걸릴 조건을 아직 못 갖췄고, 검색 말고 들어올 길도 없는 상태”입니다. 영향이 큰 순서로 정리하면 다음과 같습니다.

1
발행 형식 문제 추정 — 글을 HTML 디자인판(카드·형광펜·CSS)으로 만들어 네이버 에디터에 넣고 있습니다. 네이버 스마트에디터 ONE에는 HTML 붙여넣기 기능이 없어 카드·색상·체크 표시가 깨지거나, 미리보기 화면을 복사하면 자리표시 문구([대표 사진], [스마트스토어 주소], [현장 한마디])가 그대로 남기 쉽습니다. 미완성처럼 보이는 글은 독자도 검색도 외면합니다.
2
축적량·기간 부족 확인됨 — 지금의 블로그 전략(주 2회, 냉난방 주제 집중)은 2026년 8월 25일에 시작됐습니다. 네이버는 블로그 단위 신뢰도(C-Rank)를 수주~수개월 누적으로 평가하므로, 4주 만에 방문자가 없는 것은 실패가 아니라 아직 평가 전 단계입니다. 다만 그 전 글(일상·다른 주제)이 많다면 주제 집중도가 낮게 잡혀 있습니다. 확인 필요 전체 글 수와 냉난방 글 수.
3
상호 검색 충돌 확인됨 — “위너에어컨”을 검색하면 LG 휘센 ‘위너’ 제품이 먼저 나옵니다. 상호로는 손님이 못 찾아오고, 지역·업종 키워드 글로만 유입이 생기는데 그런 글이 아직 적습니다.
4
검색 밖 유입 경로 부재 추정 — 스마트스토어 상품 페이지, 스레드·인스타 프로필, 구글 비즈니스 프로필, 네이버 스마트플레이스 어디에도 블로그 주소가 연결되어 있다는 자료가 없습니다. 이웃 수도 적을 가능성이 큽니다. 확인 필요
5
직접 경험·원본 사진 부족 추정 — 규칙 v2.1은 개념 그림·썸네일을 AI 이미지로 만들도록 되어 있고, 현장 사진은 “자리만” 표시합니다. 원고에 남은 [현장 한마디] 자리처럼 실제 경험이 비어 있으면 네이버가 가장 중요하게 보는 ‘직접 겪은 글’ 신호가 약합니다.
결론 한 줄: 새 글을 더 쓰기 전에 이미 올린 글의 형식과 자리표시를 먼저 고치고, 블로그 밖에서 들어오는 길(스토어·SNS·플레이스 링크)을 연결한 뒤, 주 2회 원본 사진이 있는 글을 3개월 쌓는 것이 순서입니다.

2. 항목별 정밀 점검표

각 항목은 “무엇이 문제인지 → 근거 → 어떻게 고치는지 → 어떻게 확인하는지” 순서입니다.

A. 글 형식 (가장 먼저 고칠 것)

중요HTML 디자인판을 그대로 네이버에 넣는 방식은 맞지 않습니다.
  • 근거 확인됨: 작성 규칙과 템플릿이 “CSS 클래스(summary-card, point-card, hl-y 등)와 구조를 그대로 써서 HTML 파일 하나로 출력”하도록 되어 있습니다. 2025년 5월 원고에는 이모지가 “ð”로 깨진 채 들어 있고, 8월 원고에도 “ð 포인트 카드” 같은 깨진 글자가 있습니다.
  • 영향: 네이버 에디터에 브라우저 화면을 복사해 붙이면 굵게·글자색·표 정도만 남고 카드 테두리·그라데이션·✓ 기호·버튼은 사라집니다. 코드 자체를 붙이면 코드가 글자로 노출됩니다. 어느 쪽이든 읽기 어렵고, 깨진 글자는 품질 감점 요인입니다.
  • 고치는 법: 글은 네이버 에디터 기본 요소로만 만듭니다. 소제목(위너 블루 #004E82, 굵게, 19px 안팎), 인용구(핵심 한 줄), 구분선, 굵게·글자색·형광펜(배경색) 2~3가지, 표(비교·비용), 사진·동영상, 링크. 카드 대신 “✔ 목록” 문장을 씁니다. HTML 원고는 “내용 초안”으로만 쓰고, 에디터에서 다시 조립합니다.
  • 확인 확인 필요: 최근 글 3개를 휴대폰으로 열어 (1) 카드가 깨져 보이는지 (2) “ð”, “{ }”, “[ ]” 글자가 남았는지 (3) 문단이 벽처럼 붙었는지 보세요.

B. 자리표시 잔존

  • 근거 확인됨: 규칙 문서는 [스마트스토어 주소], [관련 글 링크: N번 제목], [현장 한마디: …], [사장님 확인]을 자리표시로 남기고 사장님이 발행 전에 채우도록 합니다. 초보자가 매번 빠짐없이 채우기는 어렵습니다.
  • 영향: 한 글이라도 이대로 발행되면 검색·AI 요약 모두 미완성 문서로 봅니다.
  • 고치는 법: 발행 전에 함께 드린 blog_check_tool.html의 “발행 전 검사”로 본문을 검사하면 [ ] 자리표시·깨진 글자·과장 표현을 자동으로 찾습니다.
  • 확인 확인 필요: 블로그 안 검색창에 “확인”, “사장님”, “주소]”를 검색해 보세요.

C. 분량과 구조

  • 근거 확인됨: 규칙은 2,000~3,000자인데 8월 25일에 “5,000자 확장판” 원고가 만들어졌습니다. 5,000자 글은 모바일에서 끝까지 읽히기 어렵습니다.
  • 고치는 법: 한 글 한 주제, 2,000~3,000자. 5,000자 원고는 “여름 끝 정리(송풍·필터)”와 “내년 첫 가동·점검 신호” 두 편으로 나누는 편이 낫습니다.
  • 첫 문단은 정의형(“○○란 ~입니다”), 소제목은 질문형(“실외기에서 김이 나면 고장인가요?”)으로 — 네이버 AI 브리핑이 인용하는 형태입니다.

D. 제목과 키워드

  • 근거 확인됨: 2025년 5월 원고 제목은 “에어컨 자가설치와 전문가 설치의 모든 것: 내게 맞는 선택은?” 처럼 검색어가 앞에 없고, 본문은 “위너에어컨이 완벽 비교!”, “시원하게 해결해 드립니다!” 등 과장 톤입니다. ‘완벽’은 쓰지 않기로 한 표현입니다.
  • 고치는 법: 제목 25~35자, 검색어를 앞 15자 안에, 상호는 뒤로. 키워드는 “에어컨”처럼 큰 단어가 아니라 “냉난방기 평형 계산”, “상가 냉난방기 설치”처럼 2~3어절.
  • 확인 확인 필요: 9월 10일에 만든 키워드 200개 검색량 확인 파일을 실제로 광고 키워드도구에 넣어 봤는지. 아직이라면 5개씩 넣어 월 검색량 500~5,000 구간의 10개를 먼저 고르세요.

E. 사진·동영상·AI 이미지

  • 근거 확인됨: v2.1 규칙은 개념 그림·썸네일을 AI로 생성하고 현장 사진은 자리만 둡니다. 스레드에는 8월 12일 공장 사진 등 실제 현장 사진이 있었습니다.
  • 고치는 법: 스레드에 올린 현장 사진을 블로그에도 5장 이상 넣습니다(번호판·간판 가림). 파일명은 “구리-공장-냉난방기-설치.jpg”처럼 키워드로. AI 이미지는 개념 설명용 1장 이내로 제한하고 “AI로 제작” 표시. 실제 시공처럼 보이는 AI 이미지는 쓰지 않습니다.

F. 상호·브랜드 표기

  • 근거 확인됨: “위너에어컨” 검색은 LG 휘센 위너 제품이 차지합니다. 사업자등록증 상호는 “위너에어시스템”, 견적서 상호는 “위너에어컨”, 고양 “힐링에어컨”은 별도 번호·주소입니다.
  • 고치는 법: 블로그명·별명·소개글·본문은 항상 “구리 위너에어컨” 또는 “남양주 위너에어컨”. 스마트플레이스·스토어·블로그의 상호·전화·주소를 하나로 맞춥니다. 힐링에어컨(고양) 이야기는 이 블로그에 섞지 않습니다.
  • 확인 확인 필요: 네이버 스마트플레이스에 “위너에어컨(구리)”가 등록되어 있는지, 등록 전화가 010-9082-2174인지.

G. 블로그 계정 설정

  • 확인 필요 블로그명·별명에 지역+업종이 들어가 있는지 (예: “구리·남양주 에어컨 냉난방기 설치 위너에어컨”).
  • 확인 필요 프로필 사진이 사장님 실물이나 작업 장면인지. 25년 경력이 프로필 소개글에 한 줄로 있는지.
  • 확인 필요 카테고리가 “냉난방 정보·팁 / 설치 사례(구리·남양주) / 안내” 정도로 정리돼 있는지. 옛 카테고리(일상·해외직구 등)가 앞에 나와 있으면 뒤로 보냅니다.
  • 확인 필요 글마다 ‘주제 설정’을 비워 두지 않고 한 가지(예: 인테리어·DIY 또는 상품리뷰)로 고정했는지.

H. 과거 글 처리

  • 근거 확인됨: 규칙 문서 자체가 “기존의 일상 글”을 언급하고, 2023년 자료에는 셀카봉·초인종 등 해외직구 상품을 위너에어컨 이름으로 올린 기록이 있습니다. 블로그에도 그런 글이 있다면 주제 집중도가 크게 떨어집니다. 확인 필요
  • 고치는 법: 한꺼번에 삭제하지 않습니다(단기간 대량 삭제도 감점). 명백히 다른 주제 글은 주 5개 이내로 ‘비공개’ 전환, 나머지는 새 글을 쌓아 냉난방 비중을 70% 이상으로 역전시킵니다.

I. 발행 리듬과 초기 반응

  • 근거 확인됨: 8월 25일 이후 스레드는 매일 계획이 있지만, 블로그 발행 계획·기록은 없습니다. 확인 필요 최근 4주 블로그 발행 수.
  • 고치는 법: 화·금처럼 요일을 고정해 주 2회(정보 글 1 + 설치 사례 1). 발행 직후 스레드·인스타에 공유, 당일 댓글 답글. 발행 후 24~48시간 반응이 노출에 반영됩니다.

K. 통계를 보는 습관

  • 방문자 수보다 검색 유입이 생긴 글 수와 유입 검색어 종류가 늘어나는지를 봅니다. 초기에는 하루 3~5명이어도 검색어가 늘면 방향이 맞는 것입니다.
  • 함께 드린 도구의 “블로그 상태 기록” 탭에 매주 한 번 숫자를 적으면 추세와 진단이 자동으로 나옵니다.

4. 2차 정밀 분석을 위해 보내 주시면 좋은 화면

  1. 블로그 앱 → 통계 → 방문 분석(최근 3개월), 유입 분석(유입 경로·검색어) 화면
  2. PC에서 내 블로그 → 전체 글 목록(제목·날짜·카테고리가 보이게, 여러 장이어도 괜찮습니다)
  3. 최근 글 3개를 휴대폰으로 연 화면(처음부터 끝까지 스크롤 캡처)
  4. 블로그 홈(프로필·블로그명·카테고리·이웃 수가 보이는 화면)
  5. 글쓰기 화면의 주제 설정과 발행 설정

이 화면들이 있으면 “어떤 글이 검색에 걸리고 있는지, 어떤 글부터 고쳐야 하는지”를 글 단위로 짚어 드릴 수 있습니다.
