# 위너에어컨 네이버 블로그 정밀 진단 (2026-09-18)

대상 블로그: `blog.naver.com/as1096` (구리·남양주 위너에어컨)

이 폴더에는 블로그 방문자 부진 원인을 진단한 **보고서**와, 앞으로 글을 올릴 때마다 쓰는 **점검 도구**가 들어 있습니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `report.html` | 정밀 진단 보고서 (더블클릭으로 열림) |
| `blog_check_tool.html` | ① 발행 전 검사기 ② 블로그 상태 기록표 ③ 개선 체크리스트 |
| `open_tool.bat` | 위 두 파일을 한 번에 여는 실행 파일 |
| `README.md` | 이 설명서 |

인터넷 연결이 없어도 동작하며, 기록은 사용하는 컴퓨터의 브라우저 안에만 저장됩니다.

## 실행 방법

1. 이 폴더(`blog-audit`)를 Windows 바탕화면 등 편한 곳에 내려받습니다.
2. `open_tool.bat`을 더블클릭합니다. (또는 `blog_check_tool.html`을 더블클릭)
3. 브라우저가 열리면 위쪽 탭에서 원하는 기능을 고릅니다.

### ① 발행 전 검사
1. 핵심 키워드, 제목, 본문(글자만)을 붙여넣습니다.
2. 직접 찍은 사진 수, 동영상 수, AI 이미지 사용 여부, 내 글 링크 수를 적습니다.
3. **검사하기**를 누르면 점수와 함께 “수정 / 보완 / 통과” 항목이 나옵니다.
4. **수정 필요 0개**일 때만 발행합니다. **결과 복사**로 결과를 메모해 둘 수 있습니다.

검사 항목: HTML 코드·깨진 글자, `[ ]` 자리표시 잔존, 제목 길이·키워드 위치, 본문 분량, 키워드 횟수, 정의형 첫 문단, 질문형 소제목, 긴 문단, 과장·단정 표현, 취급하지 않는 서비스(세척·수리·이전설치) 표기, 지역+상호·연락처, 개인정보(전화·상세 주소·차량번호), 사진·동영상·AI 이미지, 내 글 링크·스토어 링크·댓글 유도, 직접 경험 문장.

### ② 블로그 상태 기록
네이버 블로그 앱 → 통계에서 본 숫자를 매주 한 번 적고 **기록 저장**을 누르면 진단이 나옵니다. **CSV로 저장**(엑셀에서 한글 정상)과 **표 복사**를 지원합니다.

### ③ 개선 체크리스트
오늘 → 이번 주 → 4주 → 3개월 순서로 할 일이 정리되어 있습니다. 체크 상태는 저장됩니다.

## 진단 요약

이번 작업 환경은 네이버 도메인 접속이 차단되어 블로그 화면·통계를 직접 열지 못했습니다. 아래 판단은 드라이브에 저장된 블로그 작성 규칙·원고·템플릿·키워드 파일, 스레드 계획, 사업자 자료와 웹 검색을 근거로 했습니다. 실제 화면에서만 알 수 있는 항목은 “확인 필요”로 표시했습니다.

방문자가 없는 원인 (영향이 큰 순서):

1. **발행 형식 문제 (추정)** — HTML 디자인판(카드·CSS)을 네이버 에디터에 넣는 방식이라 카드·색상이 깨지거나 `[대표 사진]`, `[스마트스토어 주소]`, `[현장 한마디]` 같은 자리표시가 남기 쉽습니다. 원고에는 “ð”로 깨진 이모지도 있었습니다.
2. **축적량·기간 부족 (확인됨)** — 현재 전략은 2026-08-25 시작. 네이버는 블로그 단위 신뢰도를 수주~수개월 누적으로 평가합니다. 이전 일상·다른 주제 글이 많다면 주제 집중도가 낮습니다.
3. **상호 검색 충돌 (확인됨)** — “위너에어컨”은 LG 휘센 ‘위너’ 제품명과 겹쳐 상호 검색으로 유입되지 않습니다. “구리 위너에어컨 / 남양주 위너에어컨”으로 표기해야 합니다.
4. **검색 밖 유입 경로 부재 (추정)** — 스마트스토어·스레드·인스타·구글 비즈니스 프로필·스마트플레이스에 블로그 링크가 연결된 자료가 없습니다.
5. **직접 경험·원본 사진 부족 (추정)** — AI 이미지 중심, 현장 사진은 자리표시만. 네이버가 가장 중요하게 보는 “직접 겪은 글” 신호가 약합니다.

자세한 항목별 점검표와 실행 계획은 `report.html`을 여세요.
