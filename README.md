# 위너에어컨 정책 변경 모니터

네이버 스마트스토어 판매자 정책, 대한민국 전자상거래·통신판매업 규정, 에어컨 온라인 판매 관련 안전·효율 표시 기준을 매일 확인하고 **판매 운영에 영향을 주는 관련 문구가 바뀐 경우에만 GitHub 이슈로 알리는 자동화**입니다.

## 작동 방식

- 매일 **오전 9시 17분(KST)** 공식 공개 페이지 15곳을 확인합니다.
- 첫 실행은 현재 내용을 기준선으로 저장하며 변경 알림을 만들지 않습니다.
- 이후 상품등록, 사업자 전환, 리뷰, 노출, 판매자 계정, 통신판매업 신고, 설치비·추가비용 고지, KC·효율등급 등 지정 키워드가 포함된 문구가 달라지면 이슈를 생성합니다.
- 생성된 이슈는 저장소 소유자에게 자동 배정되어 GitHub 알림 설정에 따라 웹·앱·이메일로 전달됩니다.
- 알림에는 다음 항목이 포함됩니다.
  1. 무엇이 바뀌었는지
  2. 위너에어컨에 왜 중요한지
  3. 즉시 확인할 조치

## 감시 범위

### 네이버 스마트스토어 — 6개 출처

- 판매자센터 공지·도움말
- 상품등록·수정·네이버쇼핑 노출
- KC·상품정보·그룹상품
- 리뷰·베스트상품·스토어 등급
- 개인/사업자 정보변경 및 통신판매업 신고번호
- 주·부·통합매니저와 계정 권한

### 대한민국 전자상거래·통신판매업 — 7개 출처

- 전자상거래 등에서의 소비자보호에 관한 법률·시행령·시행규칙
- 전자상거래 상품 등의 정보제공 고시
- 정부24 통신판매업 신규·변경·휴업·폐업·영업재개 신고 안내

### 에어컨 온라인 판매 — 2개 출처

- 전기용품 및 생활용품 안전관리법 시행규칙
- 효율관리기자재 운용규정
- KC 인증, 전기냉방기 효율등급, 설치·배송·추가비용 사전고지 관련 변경

세부 출처와 키워드는 [`sources.json`](sources.json)에서 관리합니다.

## 알림 판정

- **즉시 확인:** 시행·적용·개정, 신고, 운영제한, 판매중지, 노출중단, 사업자 전환, 양도양수, KC·효율등급, 설치비·추가비용 관련 변경
- **7일 이내 확인:** 리뷰 정렬, 전시·추천 기준, 도움말 절차처럼 판매 운영에 영향을 주지만 즉시 위반 위험은 낮은 변경
- **모니터링 점검:** 특정 공식 출처가 3회 연속 확인되지 않거나 전체 출처 확인이 실패한 경우

## 수동 실행

GitHub 저장소의 **Actions → Winner Aircon policy monitor → Run workflow**에서 즉시 실행할 수 있습니다.

## 파일 구성

- `.github/workflows/policy-monitor.yml` — 매일 실행 및 이슈 생성
- `policy_monitor.py` — 페이지 정규화, 변경 비교, 중요도 판정, 보고서 작성
- `sources.json` — 공식 출처, 키워드, 영향 설명, 확인 조치
- `state/policy_state.json` — 최초 실행 후 생성되는 비교 기준선

## 한계와 안전장치

- 공개된 공식 페이지만 확인합니다. 스마트스토어센터 로그인 후에만 보이는 개별 팝업, 쪽지, 이메일은 별도로 확인해야 합니다.
- 페이지 전체를 보관하지 않고 관련 키워드가 포함된 짧은 문구만 기준선에 저장합니다.
- 자동 감지는 법률 해석을 확정하지 않습니다. 알림 발생 시 적용일, 적용대상, 경과조치와 공식 원문을 최종 확인합니다.
- 사이트 구조 변경으로 내용을 읽지 못하면 정책 변경으로 오인하지 않고 모니터링 점검 이슈를 생성합니다.
